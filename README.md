# 目覚めたら表？（mezame-omote）

眠りの実験で、コインが表なら a 回、裏なら b 回起こされる。「実験ごと」と「起きた回ごと」の2通りに数えたとき、表の割合はいくつになるかを当てる1日5問のゲーム。正解すると、同じ決まりで3000回まわしたようすが出て、2段目（目覚めの数・1回目の目覚めの割合など）を選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/mezame-omote/>

- 話のもとは哲学の「眠れる美女（Sleeping Beauty）問題」。A. Elga「Self-locating belief and the Sleeping Beauty problem」Analysis 60(2), 2000（1/3 と答えた）<https://princeton.edu/~adame/papers/sleeping/sleeping.pdf> と、D. Lewis「Sleeping Beauty: reply to Elga」Analysis 61(3), 2001（1/2 と答えた）<https://doi.org/10.1093/analys/61.3.171> 。
- どちらが正しいかは、いまも意見が分かれています。このゲームは、何を1回と数えるかで数が変わることを確かめるもので、どちらかに決めつけません。
- 出てくる実験・人物はすべて架空です。お金・賭けは出てきません。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。結果の「共有」を押したときだけ、次の文が選んだサービス（X・LINE など）に渡ります：ゲームの名前・回の番号と日付・各問の印の並び（🟢＝まちがいもヒントもなし、🔶＝まちがいかヒントが1つ、🔺＝2つ以上。ヒントもまちがいと同じに数えます）・遊ぶページの URL・ハッシュタグ（#目覚めたら表 #学べる無料ゲーム）。
